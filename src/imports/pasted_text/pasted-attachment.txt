Crie uma landing page premium, elegante, moderna e altamente visual para um fotógrafo profissional.

## MATERIAL FORNECIDO

Eu vou fornecer **uma imagem contendo a logo da empresa/fotógrafo**.

Essa logo será o principal material visual real disponível nesta primeira versão da landing page.

**IMPORTANTE:**

* Utilize a logo fornecida na própria interface.
* A logo deve ser incorporada de maneira elegante e profissional.
* Analise visualmente as características da logo, incluindo cores, estilo, formas e identidade.
* Use a logo como referência para construir a identidade visual da página.
* Não altere, distorça ou redesenhe a logo.
* Preserve suas proporções originais.
* Não crie outra logo.
* Não invente elementos de identidade visual que entrem em conflito com a logo.
* A identidade da landing page deve complementar a logo, e não competir com ela.

**As fotografias profissionais ainda NÃO serão fornecidas.**

Portanto:

* Utilize placeholders elegantes para as fotografias.
* Não invente fotografias específicas do fotógrafo.
* Não utilize fotos genéricas com aparência de banco de imagens barato.
* Crie áreas visualmente sofisticadas preparadas para receber as fotografias reais posteriormente.
* Toda a estrutura deve permitir substituir os placeholders pelas fotografias reais sem precisar reconstruir a página.

---

# 1. CONCEITO GERAL

Não quero uma landing page genérica.

Quero uma **experiência digital premium para um fotógrafo profissional**, com estética semelhante a um portfólio editorial/cinematográfico de alto padrão.

A primeira impressão deve transmitir:

* Sofisticação
* Exclusividade
* Criatividade
* Profissionalismo
* Qualidade
* Sensibilidade artística
* Alto valor percebido

A página deve ser visualmente marcante, mas sem exageros.

Priorize:

**minimalismo + fotografia + tipografia + movimento + espaço negativo.**

---

# 2. IDENTIDADE VISUAL BASEADA NA LOGO

A logo fornecida deve ser utilizada como referência principal da identidade visual.

Analise:

* Cores predominantes
* Contraste
* Formas
* Tipografia presente na logo
* Estilo visual
* Sensação transmitida pela marca

A partir disso, desenvolva uma identidade complementar para toda a landing page.

Se a logo utilizar cores neutras, mantenha uma estética sofisticada e neutra.

Se possuir uma cor de destaque, utilize essa cor de forma estratégica e discreta em:

* detalhes;
* linhas;
* pequenos indicadores;
* hover states;
* botões;
* elementos de navegação.

Não espalhe a cor da marca excessivamente pela página.

A logo deve continuar sendo um dos elementos mais reconhecíveis da interface.

---

# 3. HERO — PRIMEIRA IMPRESSÃO

A primeira tela deve ocupar aproximadamente 100vh e ser extremamente impactante.

Não criar um Hero tradicional com apenas:

"Olá, sou fotógrafo"

e um botão.

Quero uma experiência visual inovadora.

A logo deve aparecer de maneira elegante no Hero ou na navegação inicial, sem ficar excessivamente grande.

Criar uma grande área visual preparada para receber posteriormente uma fotografia de destaque.

Utilizar inicialmente um placeholder sofisticado.

Apresentar:

[NOME DO FOTÓGRAFO]

PHOTOGRAPHY / VISUAL STORIES

ou uma composição semelhante.

O texto deve ser facilmente substituível posteriormente.

---

# 4. HERO INTERATIVO

O Hero deve possuir uma experiência de movimento sofisticada.

Quando o usuário começar a rolar a página:

* a imagem deve se movimentar suavemente;
* aplicar parallax;
* realizar pequeno zoom;
* alterar escala;
* movimentar o texto em velocidade diferente;
* revelar gradualmente a próxima seção;
* utilizar máscaras ou efeitos de revelação;
* criar sensação de profundidade.

A transição deve parecer cinematográfica.

Não quero animações rápidas ou exageradas.

Quero uma sensação de:

**"Estou entrando em uma experiência visual."**

# 17. ANIMAÇÕES

Utilizar animações modernas e sofisticadas.

Priorizar:

* Parallax
* Scroll reveal
* Image scale
* Image reveal
* Mask transitions
* Horizontal scrolling
* Text reveal
* Fade
* Transform
* Microinterações

As animações devem ser lentas, fluidas e elegantes.

Evitar:

* efeitos chamativos;
* bouncing excessivo;
* animações rápidas;
* excesso de elementos se movimentando simultaneamente.

A animação deve melhorar a experiência, não distrair o usuário.

---

# 18. CURSOR

No desktop, criar um cursor personalizado minimalista.

Ao passar sobre imagens:

VIEW

Ao passar sobre links:

pequena alteração visual.

No mobile, remover o cursor personalizado.

# 19. RESPONSIVIDADE

A página deve ser totalmente responsiva.

Desktop:
experiência cinematográfica completa.

Tablet:
reduzir a complexidade das animações.

Mobile:
criar uma experiência própria para touch.

Não simplesmente reduzir o layout desktop.

Garantir:

* textos legíveis;
* imagens adequadas;
* navegação funcional;
* botões acessíveis;
* animações leves;
* nenhuma quebra visual.

---

# 20. PERFORMANCE

Priorizar performance.

Utilizar:

* transform;
* opacity;
* lazy loading;
* imagens responsivas;
* componentes reutilizáveis.

Respeitar:

prefers-reduced-motion

Caso o usuário prefira reduzir animações, diminuir ou desativar os efeitos mais complexos.

# 26. RESULTADO FINAL

O resultado deve parecer um **portfólio premium desenvolvido especificamente para um fotógrafo profissional**, e não um template genérico.

A experiência deve transmitir:

sofisticação;
arte;
profissionalismo;
exclusividade;
qualidade.

A prioridade é:

1. Impacto visual
2. Logo e identidade da marca
3. Fotografia
4. Experiência de navegação
5. Tipografia
6. Animações
7. Conversão
8. Performance

Lembre-se:

**A única imagem real fornecida inicialmente será a LOGO.**

Utilize essa logo na landing page e construa todo o restante da experiência utilizando placeholders sofisticados para as fotografias.

Posteriormente, eu fornecerei as fotografias reais e elas deverão poder substituir os placeholders sem necessidade de reconstruir o layout.

Não invente uma logo alternativa.

Não altere a logo fornecida.

Não deixe a página com aparência de template.

Crie uma experiência visual premium, elegante, inovadora e memorável.
